# Quant-Arena manuscript

主文档 `main.tex`。仅发布 benchmark，不将交互实现包装为方法贡献。

## 当前快照和结果口径

使用 2026-10-18 20:27 压缩包：106 episodes。E1 100条（24完成、17失败、4运行、55取消）；E2 errors-only 6条（4完成、2运行）。分组必须包含suite，E2不并入E1 vanilla。四个已完成记录无总分，保留金融结果，不补零。

主文使用已核对的离线现金账户结果及 `cash_excess_blend_v1` 离线总分；不声称这些已经替换在线榜单。主表为全部24个E1完成记录的均值±样本标准差；E2单列。历史加性金融结果保留在附录，不跨口径混算。

核对2,712个JSONL/CSV字段，并独立复算52个可用窗口的208个现金账户统计量。金融超额相对毛等权市场参考，它不是成本匹配的交易基线。没有中间候选的样本外结果，不能宣称研究轨迹的改善直接证明泛化增益。

## 披露边界

- 样本内公开新版超额收益评分项及研究公式。
- 样本外仅说明预测质量、稳定性、收益、风险、换手、资源和特征多样性等维度，保留总分输出，不公开评分构造、权重或分解。
- 不公开精确买卖时点、数据截止时点、价格对齐公式或具体费率。
- 内部原始资料留在父级research目录，不属于论文发布包。

## 生成与编译

在父级项目运行 `python3 research/summarize_results.py` 后运行 `python3 research/analyze_snapshot_2027.py`。两步分别保留历史值及生成当前主表、资源表与反馈对照表。它们只处理本地文件，不重新执行私有终测评分或访问线上服务。

Overleaf 使用 pdfLaTeX，主文档为 `main.tex`；本地运行 `bash build.sh`。

当前改进分支以 `main` 的实证材料、评分版本和披露范围为准。写作修订补充评估术语，明确完成样本统计的分母、反馈比较的限制以及指标与总分的可用性。实验表格和评分公式沿用主分支；旧协议稿的空白结果和另一套评分公式已移出当前稿。
