# Quant-Arena manuscript

主文档 `main.tex`。仅发布 benchmark，不将交互实现包装为方法贡献。

## 当前稿件和结果口径

主表按模型和研究设置展示一条保留策略，沿用 leaderboard 在合格提交中按总分选择的结果；同分时保留既有条目。表格中的分数和金融指标对应同一条策略，不报告重复运行的均值或标准差。缺失结果保持缺失，不补零。

收益、风险和净值图使用现金账户结果；超额收益相对毛等权市场基准。主表与 2024 年净值图使用相同的已选 iterative 策略。Kelper-1 是闭源参考策略。Errors-only 反馈对照单独展示，不并入主实验设置。

特征声明上限为 300；多样性使用固定尺度 `min(K,32)/32`。附录保留 benchmark 规格、信息边界及金融评价细节，平台实现介绍不再纳入。研究中间候选的进步按研究期反馈解释，不视为样本外收益提升。

## 披露边界

- 样本内公开新版超额收益评分项及研究公式。
- 样本外仅说明预测质量、稳定性、收益、风险、换手、资源和特征多样性等维度，保留总分输出，不公开评分构造、权重或分解。
- 不公开精确买卖时点、数据截止时点、价格对齐公式或具体费率。
- 内部原始资料留在父级research目录，不属于论文发布包。

## 生成与编译

论文编译所需的 LaTeX、图表和模型 logo 均包含在本仓库。图表数据的内部核验记录和独立实验预览保留在论文仓库之外。
